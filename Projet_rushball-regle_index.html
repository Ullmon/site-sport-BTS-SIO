Régles

Régles générales


- Les 2 joueurs commencent derrière la ligne de départ

- L'accessoire doit rester entre les jambes lorsque cela est demandé par la manche

- Le joueur doit réaliser le parcours jusqu'a a la ligne d'arrivée

- Si me joueur fait tomber son accessoiore, une pénalité est appliquée selon la marche

- Le chronomètre est arrêté lorsque le joueur franchit la ligne d'arrivée

- Le vainqueur est celui qui posséde le meilleur temps total aprés les 3 manches
